timeout

Timeouts HTTP padronizados sobre httpx.

O SDK fornece clientes httpx prontos para uso (sync e async) pré-configurados com o timeout definido por sme_sidecar_sdk.config.Settings.

Exemplo

>>> from sme_sidecar_sdk.resilience.timeout import build_sync_client
>>> with build_sync_client() as client:
...     response = client.get("https://example.org")

retry

Política de retry apoiada em tenacity.

Expõe retry_policy(), uma fábrica enxuta que monta o Tenacity utilizando as configurações fornecidas por sme_sidecar_sdk.config.Settings. Quando o retry está desabilitado, o decorador resultante torna-se um no-op.

Exemplo

>>> from sme_sidecar_sdk.resilience.retry import retry_policy
>>> @retry_policy()
... def fetch():
...     return httpx.get("https://example.org")

circuit_breaker

Circuit breaker construído sobre pybreaker.

Fornece um registry de circuit breakers, escopo de processo, indexado por nome, de modo que chamadores que compartilham o mesmo destino compartilhem o mesmo estado de breaker.

Exemplo

>>> from sme_sidecar_sdk.resilience import get_circuit_breaker
>>> breaker = get_circuit_breaker("turmas-api")
>>> @breaker
... def call_turmas():
...     ...

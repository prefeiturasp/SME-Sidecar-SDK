runtime

Fachada de alto nível que expõe o ponto de entrada configure().

Este módulo é a superfície de importação estável para os consumidores (from sme_sidecar_sdk import runtime; runtime.configure()). Carrega as Settings uma vez e expõe os toggles ativos por meio de RuntimeState.

Exemplo

>>> from sme_sidecar_sdk import runtime
>>> state = runtime.configure()
>>> state.settings.timeout_seconds
10.0
class sme_sidecar_sdk.runtime.RuntimeState(settings, timeout_enabled, retry_enabled, circuit_breaker_enabled, logging_enabled, tracing_enabled)[código-fonte]

Base: object

Snapshot dos recursos de resiliência e observabilidade ativos.

Variáveis:

  • settings – Configuração efetiva utilizada durante o configure.

  • timeout_enabled – True quando o wrapper de timeout padronizado está habilitado.

  • retry_enabled – True quando o decorador de retry está habilitado.

  • circuit_breaker_enabled – True quando o circuit breaker está habilitado.

  • logging_enabled – True quando os logs estruturados estão ativos.

  • tracing_enabled – True quando o provider OpenTelemetry está ativo.

Parâmetros:

  • settings (Settings)

  • timeout_enabled (bool)

  • retry_enabled (bool)

  • circuit_breaker_enabled (bool)

  • logging_enabled (bool)

  • tracing_enabled (bool)

sme_sidecar_sdk.runtime.configure(settings=None)[código-fonte]

Inicializa o runtime do SDK no processo atual.

Idempotente: chamadas subsequentes reavaliam as configurações ativas. Quando SME_SDK_ENABLED é False, o estado devolvido reporta todos os subsistemas como desabilitados.

Parâmetros:

settings (Settings | None) – Configuração opcional. Quando omitida, utiliza a instância cacheada por sme_sidecar_sdk.config.get_settings().

Retorna:

Snapshot dos recursos de resiliência e observabilidade ativos.

Tipo de retorno:

RuntimeState

sme_sidecar_sdk.runtime.state()[código-fonte]

Retorna o estado capturado pela última chamada a configure().

Tipo de retorno:

RuntimeState | None

sme_sidecar_sdk.runtime.shutdown()[código-fonte]

Libera o estado do runtime do SDK.

Limpa o snapshot capturado por configure() e o cache das configurações, devolvendo o processo ao estado anterior ao boot.

Tipo de retorno:

None

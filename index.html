SME Sidecar SDK

Visão geral

Uma aplicação consumidora habilita o runtime com uma única chamada:

from sme_sidecar_sdk import runtime

runtime.configure()

Os pilares de resiliência (timeout, retry e circuit breaker) ficam expostos via os módulos em sme_sidecar_sdk.resilience e reunidos no cliente HTTP compartilhado em sme_sidecar_sdk.http.
